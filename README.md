# Florvia landing

Landing de validación para el programa piloto de Florvia, orientado a postcosechas florícolas pequeñas.

## Ejecutar

Requiere Node.js 18.18 o superior.

```bash
npm install
npm run dev
```

La landing es una sola página estática con un formulario de demostración: todavía no persiste ni envía datos. El enlace de WhatsApp también usa un mensaje genérico hasta que se defina el número comercial.

## Recursos

`public/rose-plantation-ecuador.jpg` es una foto CC0 de Wikimedia Commons, de una plantación de rosas de Ecuador. Sustituirla por una fotografía propia de postcosecha antes de publicar para representar con precisión la operación.
